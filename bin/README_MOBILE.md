# Versões autorizadas para o Casa Mobile

`versions.json` define as versões autorizadas, separadas por componente/pacote. Não é uma lista de todas as releases.

**Robô/IA: toda nova versão distribuída do mobile deve atualizar também este JSON.** Siga [o procedimento completo](../docs/MOBILE_ATUALIZACAO.md). Mantenha `enabled: false` até publicar o APK e preencher seu SHA-256.

APK distribuído por GitHub Releases, sem versionar o binário no Git. O endereço do APK é explícito em `apk_url`.
