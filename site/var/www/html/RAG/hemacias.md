# Hemacias
Palavras-chave: hemacias, eritrocitos, sangue, microscopia, YOLO, contagem, diametro, area, VCM, HCM, CHCM, RDW.
Projeto para contagem e medicao automatizada de hemacias em imagens de microscopia. Considera captura, calibracao optica, deteccao de celulas, elementos de borda, contagem e medidas morfometricas. Ha experimentos Python, web e aplicacao Lazarus, com uso experimental de YOLO. Resultados automatizados devem ser validados antes de uso clinico.
Repositorio: marcelomaurin/hemacias.
