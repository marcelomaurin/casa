# Legenda
Palavras-chave: legenda, transcricao, voz, SpeechRecognition, microfone, TCP, acessibilidade, pt-BR.
Servidor de legendas em tempo real para palestras, aulas, reunioes e apresentacoes. Captura microfone, converte fala para texto em pt-BR e distribui transcricoes a clientes TCP. A implementacao historica usa Python speech_recognition/Google e servidor TCP na porta 8097.
Repositorio: marcelomaurin/legenda.
