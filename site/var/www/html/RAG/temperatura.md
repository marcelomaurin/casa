# Temperatura
Palavras-chave: temperatura, umidade, monitoramento, farmacia, laboratorio, geladeira, sensor.
Projeto Maurinsoft de monitoramento de temperatura e umidade para ambientes criticos, incluindo farmacias, geladeiras de medicamentos, laboratorios e salas tecnicas. O objetivo e acompanhar condicoes ambientais por sensores e disponibilizar dados para supervisao e historico.
Repositorio: marcelomaurin/Temperatura.
