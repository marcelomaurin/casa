# Doctor — automacao laboratorial
Palavras-chave: Doctor, laboratorio, automacao, Lazarus, Raspberry Pi, Arduino, MySQL.
Plataforma open source e open hardware para automacao laboratorial modular, integrando software, firmware e mecanica. Aplicacoes Pascal/Lazarus para Raspberry Pi e Windows trabalham com pacientes, exames, amostragem e receitas automatizadas. O banco usa MySQL/ZeosLib e comunicacao TCP/IP e serial. Firmwares controlam motores, servos, sensores, Nextion e impressora termica.
Repositorio: marcelomaurin/doctor.
