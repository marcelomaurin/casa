# pH
Palavras-chave: pH, temperatura, eletrodo, Arduino Nano, display, laboratorio, sensor.
Projeto de medicao de pH com microcontrolador e instrumentacao eletroquimica. O firmware utiliza Arduino Nano e existe versao com display para apresentar temperatura e pH. A documentacao aborda principio de funcionamento, montagem e integracao do sensor.
Repositorio: marcelomaurin/ph.
