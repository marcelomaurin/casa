# Balanca
Palavras-chave: balanca, Toledo, PRIX 3, peso, serial, servidor 8097, automacao comercial.
Software para leitura de balancas PRIX 3 ou compativeis com protocolo Toledo. Foi homologado com PRIX 3 e pode disponibilizar o peso por servidor na porta 8097. O repositorio tambem usa Arduino para simular a balanca e permitir testes sem hardware real.
Repositorio: marcelomaurin/balanca.
